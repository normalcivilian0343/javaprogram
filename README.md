# Choose-your-own adventure game!
A simulation for users to test their survival skills after being stranded in a desert!  
Here is an example of this in Codiva: https://drive.google.com/file/d/1AnIQ4qYhZuI9tpo4U_wMQ_rt8F6Z3Awn/view?usp=sharing 
 
# Features 
The project includes:  
- Two paths for each scenario/problem faced. 
    -  One is correct, and one will help you and one will end the game
- Prompts and descriptive scenarios throughout the desert adventure. 
- If-else pathways. 

# How to use 

Click on the choose adventure.jar file (in the releases) and download it! Make sure you have java installed and then run "java -jar chooseadventure.jar" in the terminal. Enjoy!!
