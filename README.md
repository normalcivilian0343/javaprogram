# Features 
The project includes:  
- Two paths for each scenario/problem faced. 
    -  One is correct, and one will help you and one will end the game
- Prompts and descriptive scenarios throughout the desert adventure. 
- If-else pathways. 

This was a pretty simple project, with not many choices to be made, however, I decided to use if-elses, over loops, to create a simpler, more straightforward program.
